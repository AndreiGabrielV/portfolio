_Wealth Wars_ is a cross-platform, turn-based online strategy game inspired by _Risk_, where players compete to conquer the map through tactical planning and resource management. Designed to be accessible and fun for everyone, the project combines engaging gameplay with a clean, modern interface for both web and mobile platforms.

Developed by a **large multidisciplinary team**, the project involved close collaboration between frontend and backend developers and UX/UI designers working collaboratively under **Agile methodologies**. The web version was built using **Nuxt.js**, while the mobile app was developed with **Flutter**, both powered by a shared **Node** backend hosted on Hetzner Cloud for reliable and scalable performance.

Participation centered on the **frontend development**, focusing on crafting intuitive user interfaces and smooth interactions, as well as on maintaining the **project documentation**, ensuring a clear and well-organized development workflow.

The result was a polished, responsive experience that showcased the potential of teamwork and modern web technologies in game development.
